# Global Terminal Next Goal Writer

## Workflow

1. Read the phase final report, benchmark scorecard, visual QA, tests, and release report.
2. Select the lowest-scoring priority category or a corrective phase when acceptance failed.
3. Preserve the durable benchmark-parity objective.
4. Write Goal, Context, Constraints, Tasks, Done-when checks, tests, visual QA, release gates, compliance, and final response format.
5. Name exact required files and avoid broad multi-surface scope.
6. Save to `docs/NEXT_ROADMAP_EXECUTION_PROMPT.md` and write the selection rationale.
