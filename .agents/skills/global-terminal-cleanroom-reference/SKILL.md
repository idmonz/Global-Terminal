# Global Terminal Clean-Room Reference

## Workflow

1. Identify the exact archive/project/path and governing license evidence.
2. Separate product behavior observations from implementation details.
3. Classify direct-use, path-review-required, behavior-only, or blocked.
4. Treat datasets, models, fonts, images, and vendored dependencies as separate rights surfaces.
5. Write first-party acceptance criteria and contracts before implementation.
6. Recreate behavior independently for AGPL, NASA, missing-license, unclear, or proprietary references.
7. Record copied/adapted paths and notices only when permissive direct use is approved.
8. Add no-copy and release-leak tests for the affected slice.
