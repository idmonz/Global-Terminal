# Macro / Rates OpenBB-Compatible Backend

Modules:

- `lib/openbb_macro_backend.py`
- `lib/macro_regime_engine.py`
- `lib/rates.py`
- `lib/macro.py`

The backend provides unified CPI, PCE, unemployment, GDP, treasury curve, SOFR/EFFR, and credit-spread proxy payloads. Regime labels are neutral research context such as `easing`, `tightening`, `inflation pressure`, `growth slowing`, or `data gap`.
