# Phase 6L Next Goal Rationale

Updated: 2026-07-10

## Evidence-Selected Next Phase

**Phase 6M: Unified Attention Desk And Daily Review Loop.**

Phase 6L removes a storage/UX regression and proves the local sync boundary, but
hosted proof cannot advance without an external Supabase prerequisite. The next
unblocked commercial problem is user attention: important changes are split
across Watchlist changes, catalysts, exact news, Daily Brief, provider
degradation, and geopolitical transmission paths.

Phase 6M should turn the new `Attention queue` into one complete daily journey:

```text
open Global Terminal
-> see only meaningful changes since the last review
-> filter by watchlist, severity, change kind, and source health
-> open exact evidence in the existing analyst/map/news/brief surfaces
-> return with state preserved
-> review, acknowledge, snooze, or change the in-app policy
-> leave with a source-bound daily digest and no notification pressure
```

This direction is supported by TradingView watchlist/alert management, OpenBB
linked source-aware widgets, Koyfin's centralized alert center, WorldMonitor's
cross-source dedupe, and current user reports of repeated checking and
information overload.

## Guardrails

- reuse Phase 6G/6H/6I/6K/6L records; do not create another disconnected page;

- no fake live rows and no automatic provider refresh during triage;

- rerun the hosted Branch A preflight if Supabase becomes available;
- maintain versioned desktop/mobile screenshots for every visible change.

hosted product completion and no score reaches 5.
