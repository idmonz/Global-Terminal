# Goal 9 Plan

## Objective

Build a project-native unified data layer inspired by OpenBB-style routing while keeping OpenBB optional.

## Workstreams

1. Pre-flight guard: smoke, pytest, canonical functions, static universes, release hygiene.
2. Internal data layer: contracts, endpoint catalog, provider router, schema normalizers, freshness, gaps, facade.
3. Optional OpenBB runtime: endpoint resolver, real probes, runtime capability matrix.
4. Macro/rates/energy/shipping: unified payloads, regime cards, chokepoint risk proxy, Scenario/War Room evidence.
5. Portfolio/Screener/Financial Terminal: factor backend, enriched screener scores, endpoint route status.
6. AI/MCP preparation: compact context packets and endpoint manifest; no automatic LLM calls.
7. Tests, cleanup, release package, final report.

## Boundary

- OpenBB remains optional.
- Base launch does not require OpenBB or paid provider keys.
- No OpenBB or WorldMonitor source is copied into runtime modules.
- Proxy and estimated outputs are labeled.
