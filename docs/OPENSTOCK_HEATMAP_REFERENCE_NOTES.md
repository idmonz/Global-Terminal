# OpenStock Heatmap Reference Notes

Goal 10B uses OpenStock/TradingView-style heatmap usability only as a product reference: readable grouped tiles, clear color semantics, useful hover context, and fast drilldown intent.

No OpenStock source code is copied or imported. The implemented heatmap system is native to this project:

- Data comes from existing project providers, static universes, user portfolios, and internal payloads.
- Layout rows are produced by `lib/heatmap_tile_engine.py` and `lib/heatmap_layout_engine.py`.
- Tooltips and drilldowns are generated by project code.
- Optional TradingView widgets are disabled by default and labeled as external visual supplements only.
