# WorldMonitor Terminal UX Deepening

Goal 7 deepens the command-center UX while preserving the WorldMonitor reference boundary.

## Additions

- Workspace presets for Global Command Center, Equity Desk, Crypto Derivatives Desk, Energy / Geopolitics Desk, Portfolio Quant Lab, Risk Manager, Financial Terminal, and News / OSINT War Room.
- Provider health strip and status console helpers.
- Layer-first payloads with search, domain grouping, unavailable layers, freshness, caveats, time range, and region options.
- War Room right rail panel roster for live feed, AI brief, strategic posture, scenario watch, country instability, chokepoints, market impact, crypto stress, source freshness, and provider health.
- News ticker strip, Screener column/detail controls, Crypto terminal caveats, and Energy chokepoint/provider cards.

No WorldMonitor source code is copied into runtime.
