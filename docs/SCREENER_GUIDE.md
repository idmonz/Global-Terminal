# Screener Guide

`pages/13_Screener.py` provides multi-asset screening.

## Asset Classes

- Stocks
- ETFs
- Crypto
- Bonds / Rates proxies
- Commodities
- Cross-asset

## Views

- Sortable table
- Heatmap
- Scatter plot
- CSV export
- Button-triggered neutral AI summary

## Labels

The screener uses neutral labels such as:

- High momentum
- Elevated volatility
- Fundamental quality
- Valuation bucket
- Crowding risk
- Data gap

The screener does not rank assets as advice or issue trading recommendations.
## Goal 8 OpenBB Screener Backend

- Screener supports source modes: Auto, Native only, OpenBB preferred, and OpenBB only.
- OpenBB stock and ETF screener/mover data can be merged with native rows when installed.
- Crypto, rates, commodity, and cross-asset screeners remain native-only in this goal.
- Presets use neutral research candidate and watchlist language.
