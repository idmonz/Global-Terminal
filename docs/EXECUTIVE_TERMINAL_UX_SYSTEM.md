# Executive Terminal UX System

Goal 10 adds summary-first payload builders:

- `lib.executive_summary_engine`
- `lib.terminal_workspace_router`
- `lib.drilldown_recommendation_engine`
- `lib.market_briefing_cards`
- `lib.terminal_briefing_payloads`
- `lib.cross_asset_regime_summary`

The app now surfaces risk state, data confidence, provider gaps, proxy/official labels, and drill-down cards before raw tables. Drill-down cards are navigation prompts only and never action directives.

## Goal 10B Additions

Goal 10B adds `modern_visual_system`, `summary_keyword_engine`, `click_path_engine`, `market_overview_layout`, `relative_market_intelligence`, and `global_volatility_monitor` to the executive UX layer.

The Overview Terminal now has summary keywords, click-next actions, RMI, volatility rankings, internal heatmap payload metadata, and source freshness dots before deeper raw tables.
