# Research OS Product UX

Goal 11C changes the Research OS from a backend workflow layer into a product-quality workspace using card decks, compact metrics, source freshness chips, command palette states, Intel Feed payloads, and raw-payload expanders.

Major panels now expose: summary metrics, review-needed states, navigation cards, command/search result cards, Intel Feed, Live Alerts, View Presets, Layer Panel, Hotspots, activity transcript, and explicit source caveats.


## Goal 11D interaction hardening

Goal 11D turns Goal 11C payloads into safer interactive loops: action cards can call explicit workflow actions, selected reports/commits drive reader panels, and renderer helpers reduce raw table dominance while keeping raw payloads in expanders.
