# Terminal Command UX System

Goal 10 implements a native command layer inspired by function-code terminals.

## Modules

- `lib.terminal_function_registry`
- `lib.terminal_command_router`
- `lib.command_history`
- `lib.intel_scorecard_engine`
- `lib.security_signal_rules`

## Supported Examples

- `CC`
- `HELP`
- `DATA PROBE`
- `OPENBB HUB`
- `GLOBAL WAR`
- `AAPL FA`
- `BTC CRYPTO`
- `SPY PORT`
- `STRAT WORKBENCH`

Order-style commands are blocked. The router only returns workspace/page routing payloads.
