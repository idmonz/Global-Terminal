# Terminal Visual Density Guide

Goal 10 keeps dense terminal UI readable by using:

- Compact metric strips.
- Provider/source badges.
- Proxy, estimated, stale, missing-key, and historical-only labels.
- Summary-first layout before raw details.
- Tabs/expanders for raw tables and methodology.
- Plotly dark charts for research workbench visuals.

Important caveats must remain visible near the relevant output.

## Goal 10B Additions

- Keyword chips should appear near the top of major pages.
- Click-next cards should explain what to inspect, compare, or verify next.
- Heatmap payloads should include source, freshness, truth label, data gaps, and command suggestion metadata.
- Map layers should expose confidence and live/proxy/historical-only state.
- Dense panels should remain summary-first and use raw-data expanders for detail.
