# Strategy Registry

`lib/strategy_registry.py` defines research bundle candidates:

- Equal Weight Baseline
- Inverse Volatility
- Risk Parity Proxy
- Momentum Rotation
- Trend Following Basket
- Value + Quality Tilt
- Low Volatility Defensive
- Macro Regime Rotation
- Crypto Derivatives Stress-Aware
- News-Aware Event Risk
- Volatility Targeted Portfolio
- Max Diversification Proxy
- Min Variance Proxy
- Multi-Factor Blend
- Defensive Crisis Basket

Each definition includes required data, signals used, weighting method, rebalance frequency, risk controls, caveats, availability, and data gaps. Registry text is neutral and avoids directive language.
