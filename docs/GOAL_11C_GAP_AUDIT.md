# Goal 11C Gap Audit

## UI/product UX gaps

Goal 11B delivered functional backend workflow payloads, but the pages were still table/form-first and did not consistently present cards, sidebars, review queues, chips, or source caveats.

## missing external pattern adoption

External patterns had been researched but were not consistently translated into project-native Python/Streamlit payloads.

## command palette UX gaps

Command routing existed, but user-facing search did not resolve assets, crypto pairs, providers, regions, chokepoints, and strategies into contextual action cards.

## report reading workflow gaps

Reports had markdown bodies but lacked filters, sidebar/list, reader panel, review status, review notes, export actions, and source-caveat panel.

## Strategy-as-Git review workflow gaps

Strategy commits existed but lacked product-level review workflow, commit reader, guard dashboard, graph table, diff panel, artifact timeline, and linked-context review actions.

## OSINT feed/preset/layer UX gaps

Event matching existed but lacked Intel Feed, Live Alerts, View Presets, Layer Panel, Hotspots, and Locate Action payloads.

## source freshness visualization gaps

Provider/data caveats were present in raw payloads but not visually prominent enough across workspace, watchlist, reports, strategy, and OSINT panels.

## weak tests/docs remaining

Goal 11C needed payload tests for columns, labels, caveats, route commands, no fake live data, review status transitions, release hygiene, and external source-copy boundaries.
