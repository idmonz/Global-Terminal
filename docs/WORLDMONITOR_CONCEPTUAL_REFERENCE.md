# WorldMonitor Conceptual Reference

WorldMonitor is used only as a conceptual reference for Goal 6 visual workflow ideas:

- Map-first layout.
- Layer registry.
- Event layers.
- Source freshness and severity badges.
- Right-side intelligence rail.
- Chokepoint and country risk panels.
- News clustering and multi-source convergence patterns.

No WorldMonitor TypeScript code is copied into runtime. The local `external/` tree is reference-only and excluded from release packaging.
